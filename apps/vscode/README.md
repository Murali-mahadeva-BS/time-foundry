# Time Foundry

Time Foundry is a Pomodoro timer and task manager built for developers inside VS Code.

## Features

- Start, pause, and stop Pomodoro sessions from the VS Code UI
- Track tasks, estimates, and session history
- Manage projects and lists without leaving the editor
- Use quick commands to control the timer instantly
- Local session persistence with no cloud dependency

## Getting Started

1. Open VS Code.
2. Run the command `Time Foundry: Open`.
3. Use the timer panel to start a Pomodoro session.
4. Create tasks and projects in the app UI.

## Commands

- `Time Foundry: Open`
- `Time Foundry: Start Timer`
